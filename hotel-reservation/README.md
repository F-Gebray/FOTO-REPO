# 🏨 Hotel Reservation App

A modern hotel booking application built with **React + TypeScript + Vite + Redux Toolkit**.

---

## ✨ Features

- 🔍 Search hotels by destination
- 📅 Check-in / Check-out date selection
- 👥 Guest management
- 🏨 Browse hotel listings
- ⭐ Ratings and reviews system
- 💰 Room price comparison
- 🧠 Global state management with Redux Toolkit
- ⚡ Fast and responsive UI

---

## 🧠 State Management

This project uses **Redux Toolkit** for managing global state such as:

- Search filters
- Selected hotel data
- Booking details
- User selections (dates, guests)

---

## 🚀 Tech Stack

- React 18
- TypeScript
- Vite
- Redux Toolkit
- React-Redux
- Tailwind CSS
- Lucide Icons

---
