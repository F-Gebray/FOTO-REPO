🚀 Stellar v2.0 | Next-Gen Web Solutions
A premium, high-performance landing page built for a digital agency specializing in modern web experiences. This project demonstrates advanced React patterns, Framer Motion animations, and a sophisticated TypeScript architecture.

✨ Key Features
Dynamic Navigation: Advanced dropdown menus with hover-triggered state management and AnimatePresence transitions.
Modern UI/UX: A sleek "Glassmorphism" aesthetic with glowing background orbs and responsive layouts.
Performance Optimized: Built with Vite for ultra-fast Hot Module Replacement (HMR) and optimized build chunks.
Responsive Routing: Seamless client-side navigation using React Router v6.
Interactive Components: Custom-built terminal/dashboard previews and animated hero sections.

🛠️ Tech Stack

.Frontend: React 18, TypeScript, Vite
.Styling: Tailwind CSS (Utility-first styling)
.Icons: Lucide React
.Animations: Framer Motion
.Routing: React Router DOM.

🚀 Getting Started

1. Clone the repository:

   git clone https://github.com

2. Navigate to the project:

   cd webDev-page

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

📂 Project Structure

src/
├── components/ # Reusable UI components (Navbar, Hero, etc.)
├── pages/ # Individual page components for routing
├── assets/ # Static images and global styles
└── App.tsx # Main application entry and router setup
